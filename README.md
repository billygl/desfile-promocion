# Desfile y barra de la promoción

Simulación 3D del desfile por el patio del Colegio María Alvarado y de la formación de la barra frente al jurado.
Las familias aparecen solo con su código de iniciales.

- Página: `index.html` (se genera con `python build.py` a partir de `src/desfile.html` + `mapa.jpg`).
- Editar familias, asistencia y roles desde la misma página (sección "Familias").
